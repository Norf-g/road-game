# «Город дорог» — описание стиля

Минимализм: простые геометрические формы, ровные пастельные цвета, солнечный день. Никаких градиентов, текстур, бликов и мелких деталей. Всё должно читаться на экране телефона с расстояния вытянутой руки.

## Шрифт
Nunito (лицензия OFL, `game/assets/fonts/`). В картинках текста нет совсем — все надписи, включая название игры, игра рисует шрифтом. Причина: генераторы картинок искажают буквы, особенно кириллицу.

## Правила для картинок
- **Иконки интерфейса** — один цвет (графит `#3A3A40`), плоские, скруглённые, одинаковая толщина линий, глиф занимает около 70% квадрата. Иконки для кнопок скрипт сам перекрашивает в белый (кнопки тёмные), иконки статистики остаются графитовыми.
- **Иконки улучшений** — графит плюс один акцентный цвет из палитры.
- **Иконка приложения и баннер** — полноцветные, без прозрачности, в палитре выше.
- **Фон для вырезания**: всё, что должно стать прозрачным, Gemini рисует на сплошном пурпурном фоне `#FF00FF`. Настоящую прозрачность Gemini обычно не выдаёт, а пурпурный легко убрать скриптом — в самих иконках этого цвета нет.
- Нигде нет текста, букв и цифр, теней на фоне, рамок и водяных знаков.

## Как работать с Gemini
1. Готовые запросы лежат в `art/prompts/` — по файлу на группу картинок. Их собирает скрипт из `art/manifest.json`, руками их не правим:
   ```bash
   tools/.venv/Scripts/python.exe tools/art.py prompts
   ```
2. Генерируйте по одной картинке. Скопируйте запрос целиком.
3. Когда первая иконка группы получилась удачной, сохраните её в `art/references/` и прикладывайте к следующим запросам этой группы со словами «Match the style of the attached image exactly». Так вся группа выйдет одинаковой.
4. Сохраните результат в `art/inbox/` под именем из поля `id` (например, `tool_road.png`; подходят `.png`, `.jpg`, `.webp`).
5. Обработайте — скрипт уберёт фон, обрежет, приведёт к нужному размеру и положит в игру:
   ```bash
   tools/.venv/Scripts/python.exe tools/art.py process
   ```
6. Что ещё не сделано:
   ```bash
   tools/.venv/Scripts/python.exe tools/art.py status
   ```

Игра подхватывает иконки сама: если картинка есть, кнопка показывает её, если нет — текст.
