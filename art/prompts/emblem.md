# Эмблема для меню

Файл собран скриптом `tools/art.py prompts` из `art/manifest.json` — правки вносите туда.
Каждый запрос копируйте целиком. Результат сохраняйте в `art/inbox/<id>.png`.

## emblem

Итог: 512×512 → `game/assets/ui/emblem.png`

```
Minimalist flat vector emblem for the main menu of a mobile puzzle game about building roads. Simple geometric shapes, top-down view. Soft pastel palette: roads #7C7C84, buildings #8E5B3A, #4D8FD1 and #F2B33D, trees #8CC084. No gradients, no shadows, no text, no letters. Centered, occupies about 80% of the canvas. Perfectly flat solid magenta #FF00FF background filling the whole image, with nothing else on it. Square 1:1.

Subject: A closed loop of road shaped like a rounded square, with three tiny houses (brown, blue, yellow) and two round trees inside the loop.
```
